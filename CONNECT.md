# Как подключиться к своему серверу

## Владелец сервера: Windows-ПК

1. Скачайте проект через **Code → Download ZIP** в GitHub или архив из Releases. Распакуйте его полностью. Мир создастся при первом запуске.
2. Установите [Tailscale](https://tailscale.com/download), войдите в свой аккаунт и включите соединение.
3. Откройте **START.cmd**. При первом запуске компоненты скачиваются автоматически. Прочитайте [Minecraft EULA](https://www.minecraft.net/eula) и введите `YES`, если принимаете условия.
4. Дождитесь строки `Done`. Скопируйте показанный IP Tailscale и порты. При стандартных настройках Java использует TCP **25565**, Bedrock — UDP **19132**.
5. Если Windows блокирует соединение, один раз запустите **FIREWALL.cmd** от имени администратора. Правила сохраняются; после смены IP Tailscale или портов запустите его снова.
6. В [панели Tailscale](https://login.tailscale.com/admin/machines) выберите ПК → **Share** и отправьте друзьям приглашение. Они принимают его в своих Tailscale-аккаунтах. Также можно использовать устройства в одной сети Tailscale с разрешённым доступом к игровым портам.

Окно сервера должно оставаться открытым, ПК — включённым. Его можно свернуть. Завершайте игру командой `stop` в консоли и дождитесь сохранения мира.

## Друг на телефоне: Minecraft Bedrock

1. Установите и включите Tailscale. Примите приглашение владельца сервера.
2. Войдите в Microsoft/Xbox в Minecraft. Для обычного клиента это рабочий способ подключения; экспериментальная настройка сервера не гарантирует вход без аккаунта.
3. Откройте **Играть → Серверы → Добавить сервер**.
4. Название — любое. Адрес — **IP Tailscale ПК владельца**, показанный при запуске. Порт — **19132**, если владелец не изменил его.
5. Сохраните сервер и подключитесь. IP телефона, публичный IP роутера и `localhost` здесь не подходят.

## Игрок на ПК: Minecraft Java

Включите Tailscale, запустите Java **26.2** и откройте **Сетевая игра → Добавить сервер**. Адрес: `IP_ПК:25565`, например `100.70.1.2:25565`. Пример IP нужно заменить своим. Java 26.3 поддерживается через ViaVersion; при проблемах сначала проверьте обычный клиент 26.2.

## Права администратора

В консоли сервера введите `op ИгровойНик` без `/`. Для телефона используйте имя из строки подключения в журнале, включая префикс Floodgate, если он присутствует. Снять права: `deop ИгровойНик`. Белого списка нет; доступ определяется сетью Tailscale.

После смерти сервер пишет всем игрокам в чат координаты и измерение. Последнюю смерть подключённого игрока администратор может посмотреть командой `/data get entity ИгровойНик LastDeathLocation` в игре.

## Дальность и откаты блоков

Дальность картинки меняется в настройках видео телефона, при необходимости после выхода в главное меню. Сервер отправит не больше чанков, чем задано в `viewDistance`. Симуляцию задаёт владелец через `simulationDistance`: ползунок телефона не меняет симуляцию удалённого сервера. После изменения `config.json` сервер нужно остановить и запустить снова. Высокие значения увеличивают нагрузку; начинайте с 6 и 4.

Если блок появляется и исчезает только при установке далеко, повторите действие вблизи. Возможная причина — разная дальность взаимодействия Java и сенсорного Bedrock. Для проверки администратор может временно увеличить дальность **одному игроку**. В консоли сервера (без `/`):

```text
attribute ИгровойНик minecraft:block_interaction_range base get
attribute ИгровойНик minecraft:block_interaction_range base set 8
```

Запишите исходное значение первой команды. Проверьте с телефона установку того же блока с того же расстояния. Если откат исчез — увеличение дальности помогло; это меняет правила взаимодействия этого игрока. Чтобы вернуть исходные правила, выполните `attribute ИгровойНик minecraft:block_interaction_range base set ИСХОДНОЕ_ЧИСЛО`. Команды не снимают защиту спавна, границы мира или ограничения плагинов. Если блоки откатываются и вблизи, эту причину считать подтверждённой нельзя.

Geyser учитывает атрибут дальности при проверке установки блоков: [исходный код проверки](https://github.com/GeyserMC/Geyser/blob/master/core/src/main/java/org/geysermc/geyser/translator/protocol/bedrock/BedrockInventoryTransactionTranslator.java). Увеличение дальности ещё нужно проверить на вашем телефоне; сборка не применяет его автоматически ко всем игрокам.

При других ошибках запустите **CHECK.cmd**, проверьте доступ Tailscale к ПК, порты и `server/logs/latest.log`. Подробности, ограничения модов и резервные копии — в [README.md](README.md).
