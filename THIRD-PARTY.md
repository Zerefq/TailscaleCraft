# Third-party components

The MIT license in this repository covers TailscaleCraft's launcher scripts and documentation. It does not relicense downloaded components.

| Component | Purpose | Upstream |
| --- | --- | --- |
| Paper | Minecraft Java server | https://papermc.io/ |
| Geyser | Bedrock to Java protocol translation | https://geysermc.org/ |
| Floodgate | Bedrock account authentication | https://geysermc.org/wiki/floodgate/ |
| ViaVersion | Java client protocol compatibility | https://github.com/ViaVersion/ViaVersion |
| Eclipse Temurin | Optional portable Java runtime | https://adoptium.net/ |
| Tailscale | Private network; installed separately by each user | https://tailscale.com/ |

These components retain their own licenses and terms. Paper downloads upstream Minecraft files on its first launch. Every server owner must accept the [Minecraft EULA](https://www.minecraft.net/eula) themselves. No game binaries, credentials or accounts are included in the source archive. This is an independent community project.
